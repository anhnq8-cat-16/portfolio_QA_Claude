Quản lý ảnh Portfolio

Công cụ này cho phép bạn thêm / chỉnh sửa kích thước / xoá ảnh trực tiếp trên site, không cần nhờ Claude xử lý từng ảnh.

Chỉ hoạt động trên Chrome hoặc Edge trên máy tính (cần quyền File System Access). Bấm nút bên dưới và chọn đúng thư mục gốc portfolio-mason trên máy bạn.

Trình duyệt này chưa hỗ trợ. Vui lòng mở trang bằng Chrome hoặc Edge trên máy tính.
